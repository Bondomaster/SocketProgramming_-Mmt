================================================================================
   HYBRID FTP — HƯỚNG DẪN CHẠY & KIỂM THỬ (Excellent Level — Stop-and-Wait)
================================================================================

📌 YÊU CẦU: Python 3.10+, đã cài thư viện "rich"
   pip install rich

📌 THƯ MỤC LÀM VIỆC: hybrid-ftp/
   cd hybrid-ftp

================================================================================
 1. KHỞI ĐỘNG SERVER
================================================================================

Mở Terminal 1 (PowerShell):

   cd hybrid-ftp
   python -m server.main --port 2121 --root ./ftp_root

   → Server sẽ hiện: "FTP server listening on 0.0.0.0:2121  root=..."

Tuỳ chọn:
   --host 0.0.0.0      Bind address (mặc định: 0.0.0.0)
   --port 2121          TCP control port (mặc định: 2121)
   --root ./ftp_root    Thư mục gốc FTP (mặc định: ./ftp_root)

================================================================================
 2. KHỞI ĐỘNG CLIENT
================================================================================

Mở Terminal 2 (PowerShell):

   cd hybrid-ftp
   python -m client.main --port 2121

   → Client sẽ hiện: "[STATUS] Connected to 127.0.0.1:2121"
   → Prompt: "ftp>"

Tuỳ chọn:
   --host 127.0.0.1     Địa chỉ server (mặc định: 127.0.0.1)
   --port 2121          Cổng server (mặc định: 2121)
   --drop-rate 0.3      Giả lập mất gói 30% (để test RDT)
   --corrupt-rate 0.2   Giả lập hỏng gói 20% (để test CRC32)

================================================================================
 3. CÁC LỆNH FTP CƠ BẢN (Basic Level)
================================================================================

--- Đăng nhập ---
   ftp> USER admin
   ftp> PASS 1234

   Tài khoản có sẵn: admin/1234, alice/secret, guest/guest

--- Thông tin hệ thống ---
   ftp> SYST                     ← Xem loại server
   ftp> STAT                     ← Trạng thái session
   ftp> HELP                     ← Liệt kê tất cả lệnh hỗ trợ
   ftp> NOOP                     ← Kiểm tra kết nối (ping)
   ftp> TYPE A                   ← Chuyển sang ASCII mode
   ftp> TYPE I                   ← Chuyển sang Binary mode

--- Thông tin file ---
   ftp> SIZE sample.txt          ← Xem kích thước file (bytes)
   ftp> MDTM sample.txt          ← Xem thời gian chỉnh sửa cuối

--- Thoát ---
   ftp> QUIT                     ← Đóng kết nối

================================================================================
 4. QUẢN LÝ THƯ MỤC (Advanced Level)
================================================================================

   ftp> PWD                      ← Xem thư mục hiện tại
   ftp> LIST                     ← Liệt kê chi tiết (kiểu, size, tên)
   ftp> NLST                     ← Liệt kê tên file/thư mục
   ftp> MKD test_folder          ← Tạo thư mục
   ftp> CWD test_folder          ← Di chuyển vào thư mục
   ftp> CDUP                     ← Quay lại thư mục cha
   ftp> RMD test_folder          ← Xoá thư mục (phải trống)

================================================================================
 5. TRUYỀN FILE (Stop-and-Wait RDT)
================================================================================

--- Upload file (STOR) ---
   ftp> STOR <đường_dẫn_file_local>

   Ví dụ:
   ftp> STOR sample.txt
   ftp> STOR D:\Pictures\photo.jpg

   → Thanh tiến trình "Uploading..." sẽ hiện ra
   → Tự động kiểm tra SHA-256 sau khi upload xong

--- Download file (RETR) ---
   ftp> RETR <tên_file_trên_server>

   Ví dụ:
   ftp> RETR sample.txt

   → Thanh tiến trình "Downloading..." sẽ hiện ra
   → Tự động kiểm tra SHA-256 để xác nhận tính toàn vẹn

--- Upload ghi đè nối tiếp (APPE) ---
   ftp> APPE <tên_file>

   → Nối thêm dữ liệu vào cuối file đã tồn tại trên server

--- Upload tên duy nhất (STOU) ---
   ftp> STOU <đường_dẫn_file_local>

   → Server tự sinh tên file duy nhất (tránh ghi đè)

================================================================================
 6. QUẢN LÝ FILE TRÊN SERVER
================================================================================

   ftp> DELE sample.txt          ← Xoá file
   ftp> RNFR sample.txt          ← Chọn file để đổi tên
   ftp> RNTO new_name.txt        ← Đổi tên thành tên mới
   ftp> HASH sample.txt          ← Lấy SHA-256 hash từ server

================================================================================
 7. CHẾ ĐỘ TRUYỀN: PASSIVE vs ACTIVE
================================================================================

--- Passive Mode (mặc định) ---
   ftp> PASV

   → Server mở port UDP ngẫu nhiên, client kết nối tới
   → Tự động PASV trước mỗi lệnh truyền file

--- Active Mode ---
   ftp> PORT

   → Client mở port UDP, server kết nối tới client
   → Dùng khi client nằm sau NAT/firewall có thể mở port

 8. KIỂM THỬ RDT (STOP-AND-WAIT)
================================================================================

--- Test tự động (pytest) ---

   cd hybrid-ftp
   python -m pytest tests/test_rdt_stopwait.py -v

   Kết quả mong đợi: 6 passed
     ✅ test_lossless         — mạng sạch, dữ liệu byte-for-byte đúng
     ✅ test_large_file       — file 100KB (100 chunks)
     ✅ test_packet_loss      — mất gói 30%, vẫn truyền đúng
     ✅ test_corrupt_data     — hỏng gói 30%, CRC32 phát hiện, retransmit
     ✅ test_empty_file       — file rỗng (chỉ có FIN)
     ✅ test_receiver_timeout — timeout khi không có gói nào đến

--- Test thủ công: truyền file bình thường ---

   Terminal 1:  python -m server.main --port 2121 --root ./ftp_root
   Terminal 2:  python -m client.main --port 2121

   ftp> USER admin
   ftp> PASS 1234
   ftp> STOR sample.txt
   ftp> RETR sample.txt
   ftp> LIST

--- Test thủ công: giả lập mất gói 30% ---

   Terminal 2:  python -m client.main --port 2121 --drop-rate 0.3

   ftp> USER admin
   ftp> PASS 1234
   ftp> STOR sample.txt

   → Quan sát: thanh tiến trình chậm hơn do retransmit
   → SHA-256 vẫn phải khớp = dữ liệu toàn vẹn

--- Test thủ công: giả lập hỏng gói 20% ---

   Terminal 2:  python -m client.main --port 2121 --corrupt-rate 0.2

   ftp> USER admin
   ftp> PASS 1234
   ftp> STOR sample.txt

   → CRC32 phát hiện gói hỏng, sender tự retransmit
   → SHA-256 vẫn khớp = dữ liệu toàn vẹn

--- Test thủ công: giả lập cả mất gói + hỏng gói ---

   Terminal 2:  python -m client.main --port 2121 --drop-rate 0.2 --corrupt-rate 0.1

   ftp> USER admin
   ftp> PASS 1234
   ftp> STOR sample.txt

 9. KỊCH BẢN DEMO ĐẦY ĐỦ (Oral Viva)
================================================================================

--- Terminal 1: Khởi động server ---
   cd hybrid-ftp
   python -m server.main --port 2121 --root ./ftp_root

--- Terminal 2: Client demo ---
   cd hybrid-ftp
   python -m client.main --port 2121

   REM 1. Đăng nhập
   ftp> USER admin
   ftp> PASS 1234

   REM 2. Xem thư mục
   ftp> PWD
   ftp> LIST

   REM 3. Tạo & di chuyển thư mục
   ftp> MKD demo_folder
   ftp> CWD demo_folder
   ftp> PWD
   ftp> CDUP

   REM 4. Upload file (Stop-and-Wait)
   ftp> STOR sample.txt

   REM 5. Download file (Stop-and-Wait)
   ftp> RETR sample.txt

   REM 6. Đổi tên file
   ftp> RNFR sample.txt
   ftp> RNTO renamed.txt

   REM 7. Xoá file
   ftp> DELE renamed.txt

   REM 8. Xoá thư mục
   ftp> RMD demo_folder

   REM 9. Thoát
   ftp> QUIT

--- Terminal 3: Demo với mất gói (chứng minh RDT hoạt động) ---
   cd hybrid-ftp
   python -m client.main --port 2121 --drop-rate 0.3

   ftp> USER admin
   ftp> PASS 1234
   ftp> STOR sample.txt
   REM → SHA-256 vẫn khớp dù mất gói 30%!

 10. CẤU TRÚC PROJECT
================================================================================

   hybrid-ftp/
   ├── server/
   │   ├── main.py              ← Entry point server (threaded)
   │   ├── session.py           ← Session state + đăng nhập
   │   └── command_handler.py   ← Xử lý tất cả lệnh FTP
   ├── client/
   │   ├── main.py              ← Entry point client
   │   └── cli.py               ← Interactive CLI + UDP helpers
   ├── common/
   │   ├── protocol.py          ← TCP wire format (format_reply, read_line)
   │   ├── rdt_packet.py        ← Header 16 byte + CRC32 checksum
   │   ├── rdt_sender.py        ← Stop-and-Wait sender (ACK/retransmit)
   │   ├── rdt_receiver.py      ← Stop-and-Wait receiver (gói trùng/FIN)
   │   └── hashutil.py          ← SHA-256 hash utility
   ├── ftp_root/                ← Thư mục sandbox FTP
   │   └── sample.txt
   └── tests/
       ├── test_basic.py        ← Test Basic Level
       ├── test_rdt.py          ← Test RDT cũ
       └── test_rdt_stopwait.py ← Test Stop-and-Wait (Excellent Level)
